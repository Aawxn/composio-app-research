How automation processed 100 apps in under an hour and where human verification was targeted.

Gemini 2.5 Flash + Grounding

Pass 2: Automated Verifier
HTTP & Headless Browser

Human-in-the-Loop Spot Check

🎯 Ground Truth Accuracy Lift: The DealCloud Case Study

In the pilot research pass, the baseline LLM incorrectly categorized DealCloud (#10) as relying strictly on standard API Key. A human audit against live docs (api.docs.dealcloud.com/docs/token) caught that DealCloud explicitly implements an OAuth2 Client Credentials flow yielding short-lived (15-min) Bearer Tokens for authenticated REST calls.

To permanently solve this class of error, we engineered Method 1+3 (Live Page Keyword Parsing & Subpath Probing) directly into the research agent. By visiting the live page body via httpx and headless Chromium, the pipeline lifted factual accuracy from ~84% (Pass 1 raw) to ~96% (Pass 2 verified).
